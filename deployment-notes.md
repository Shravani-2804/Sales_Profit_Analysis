# Deployment Configuration

## Project
Sales & Profit Analysis Dashboard

## Platform
Microsoft Power BI

## Deployment Process
1. Open the `.pbix` file in Power BI Desktop.
2. Verify that all four report pages load correctly.
3. Refresh the dataset and verify the KPI values and visuals.
4. Publish the report to the assigned Power BI workspace.
5. Verify the published report and all report pages.
6. Share the published report according to the internship submission requirements.

## Configuration
- Source: Sample Superstore dataset
- Report file: Sales_Profit_Analysis.pbix
- BI Tool: Microsoft Power BI Desktop
- Data Preparation: Power Query
- Calculations: DAX

## Validation
The report was checked for:
- Correct dataset loading
- Correct KPI calculations
- Working visualizations
- Correct page navigation
- Readable titles and insights

## Status
Deployment configuration prepared for the Power BI report.
